Pemberitahuan privasi

Terakhir diperbarui: 2 November 2026

Dokumen awal. Sebelum dipakai sebagai kebijakan final, pemilik SiteForge perlu mengisi nama operator dan alamat dukungan publik yang ditandai di bawah.

Pemberitahuan ini merangkum data yang digunakan SiteForge untuk menyediakan akun, editor website, publikasi, dan paket berbayar. Operator layanan: [nama operator/pemilik SiteForge]. Permintaan privasi: [alamat email dukungan publik].

Data yang digunakan

  • Data akun: nama tampilan dan email. Password diproses menjadi hash; password asli tidak disimpan.
  • Data website: nama, alamat slug, teks, pengaturan tema dan SEO, serta file gambar yang kamu unggah.
  • Data sesi: token sesi disimpan dalam bentuk hash untuk menjaga login.
  • Data paket: paket, tarif, waktu siklus, dan status penagihan. Checkout ditangani oleh Xendit; SiteForge tidak menyimpan nomor kartu pembayaran.
  • Data pembatasan penyalahgunaan: hash alamat IP harian untuk membatasi pendaftaran dan publikasi. SiteForge tidak menyimpan alamat IP mentah ke tabel pembatasan D1; hash lama dibersihkan secara berkala.

Bagaimana data digunakan dan disimpan

Data akun dan website disimpan di Cloudflare D1. Gambar unggahan disimpan di Cloudflare R2. SiteForge memprosesnya untuk login, penyimpanan draft, pratinjau, publikasi, kuota, keamanan, dan dukungan. Data pembayaran tertentu diproses Xendit sesuai pengaturan checkout.

Website yang dipublikasikan

Website dengan status terbit dapat diakses publik di URL SiteForge. Gambar yang dirujuk oleh website terbit juga dapat diakses pengunjung. Draft yang belum terbit hanya dapat dibuka pemilik yang sedang login.

Cookie dan sesi

SiteForge menggunakan cookie sesi HttpOnly dan Secure untuk mempertahankan login. Cookie ini diperlukan untuk layanan akun dan tidak digunakan sebagai cookie iklan oleh SiteForge.

Ekspor, penghapusan, dan penyimpanan

Di Dashboard > Profil > Data akun, kamu dapat mengunduh salinan data atau meminta penghapusan permanen. Penghapusan menghapus akun, website, dan gambar SiteForge serta mencoba menghentikan perpanjangan Xendit yang masih aktif. Xendit dan Cloudflare dapat menyimpan catatan operasional sesuai kebijakan mereka sendiri.
